# TonButton_Autoclick (VRChat用 自動化マクロ)

VRChatのログ監視とOSC(Velocity)を用いた、ToNのボタン自動押下マクロです。
自動アップデート機構（OTA）を搭載しており、常に最新の状態でご利用いただけます。

## 📦 Release（ダウンロード）に含まれるもの

最新版は右側の **[Releases]** からダウンロードできます。

* **`TonButton_Autoclick_vX.X.X.exe`**
  **マクロ本体の実行ファイルです。通常はこちらのみをダウンロードしてください。**
  これ単体で動作するため、Pythonのインストール等は一切不要です。
* **`Source code (zip / tar.gz)`**
  ツールの透明性と安全性を証明するために公開しているソースコードです。（一般のご利用ではダウンロード不要です）

## 🚀 ダウンロードと使い方の手順

1. [Releasesページ](元ページ右側) にアクセスし、一番上にある最新の `TonButton_Autoclick_vX.X.X.exe` をダウンロードします。
2. ダウンロードしたファイルを任意のフォルダに配置し、ダブルクリックで起動します。
   * *※自作ソフトのため、初回起動時にWindowsの青い警告画面（SmartScreen）が出ることがあります。その場合は「詳細情報」をクリックし、「実行」ボタンを押してください。*
3. マクロ画面が起動したら、VRChatのログファイルを指定し、お好みの時間設定を行って「▶ 実行開始」を押してください。

### 🔄 自動アップデート機能について
本マクロには自動アップデート機能が搭載されています。
次回以降、新しいバージョンが公開された際は、マクロ起動時に自動で通知が表示されます。「はい」を押すだけで最新版をダウンロードし、古いファイルを自動的にお掃除（削除）して再起動します。
